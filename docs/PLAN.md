## Эпик 3. UI: выбор шаблона перед обработкой

### Цель
Дать пользователю выбрать шаблон перед запуском обработки и отредактировать тексты перед отправкой.

### Задачи
- [ ] Добавить селект шаблона в блок необработанной записи
- [ ] При выборе шаблона:
  - [ ] подставлять `system_prompt` в textarea системного промпта
  - [ ] подставлять `user_prompt` в поле пользовательского промпта
- [ ] Добавить явное поле/textarea для `user_prompt` (если его сейчас нет как отдельного поля)
- [ ] Сохранить UX-логику:
  - [ ] после нажатия «Обработать» показывать состояние обработки
  - [ ] использовать именно итоговые тексты из полей (с учетом ручных правок)
- [ ] Убедиться, что для уже обработанных записей текущий просмотр не ломается

- [ ] Действия:
