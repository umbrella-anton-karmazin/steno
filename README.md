# Steno

Steno — приложение для macOS, которое помогает записывать встречи и автоматически получать протоколы с помощью ИИ.

## Что это такое
Приложение объединяет запись экрана и звука, обработку записи через AI и удобный интерфейс для работы с результатами.

## Ключевые возможности
- запись встреч;
- генерация протоколов на основе записи;
- управление записями и связанными файлами;
- локализация интерфейса (RU/EN).
